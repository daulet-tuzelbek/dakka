## 🧠 How I work with data

- **Decisions over pretty numbers.** If the data can't support a decision, I say so — and frame results as *do / don't do / test further*.
- **Metric trees top-down.** Start from the business goal, break it into drivers, end with levers that have an owner.
- **MDE comes from the business.** First the smallest effect worth acting on, then sample size and test length.
- **Six ways to fool yourself** I check every experiment against: peeking, small samples, too many metrics, novelty effect, missing guardrails, p-hacking.
